## agora

estou construindo o **AppEmpregos**: marketplace de serviços avulsos.

a ideia é simples — o empregador publica um serviço, alguém perto pega o trabalho, o valor fica reservado na plataforma e os dois se avaliam no fim. pagamento visível, reputação dos dois lados.

stack do produto:

- **mobile** — Expo, React Native, TypeScript
- **api** — NestJS, Prisma, JWT
